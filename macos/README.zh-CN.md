# leon-book for macOS

[English](README.md) | [简体中文](README.zh-CN.md)

本目录包含 `leon-book` 的原生 macOS 实现。应用使用 SwiftUI 提供窗口、菜单、导航、阅读、写作和设置界面；文章网页嵌入使用系统 WebKit，不会启动 Safari 或 Chrome。

文章、草稿、设置、图片和视频都保存在本地。SQLite 负责管理结构化数据，Markdown/JSON 导出文件和媒体文件继续保存在本地文件系统中。应用不会启动 Node.js、外部浏览器或本地 HTTP 服务。

文章编辑内容停止变化 3 秒后会自动写入恢复快照；连续编辑期间每 5 分钟形成一个历史节点，默认保留 30 天。阅读页和写作工作台均可打开“版本历史”，并排查看正文差异后恢复到编辑器。自动保存不会直接覆盖已发布正文，正式内容仍由“保存草稿”或“发布”操作确认。

## 搜索与快速切换

工具栏搜索和 `⌘⇧F` 会打开统一全文搜索，范围包括文章标题、分类、标签、类型化属性、摘要、正文以及微博正文。SQLite FTS5 索引会随内容的保存、编辑、属性重命名、移入回收站和恢复自动同步，并为结果生成命中摘要。可组合使用 `tag:`、`status:draft|published`、`[属性名:值]`、`type:article|moment`、`date:YYYY-MM-DD`、`after:YYYY-MM-DD` 和 `before:YYYY-MM-DD`；方括号内的属性名和值可以包含空格。

按 `⌘O` 快速搜索并打开文章；按 `⌘P` 打开命令面板。命令面板支持模糊匹配、最近使用和固定命令；“设置 → 命令与快捷键”可以录制、移除或恢复每个命令的快捷键。菜单、URL Scheme 与 App Intents 最终都会交给同一命令注册表执行。正文行首输入 `/` 可插入标题、任务、Callout、代码块、表格、双链、嵌入或智能集合。

## 智能集合与收藏

智能集合是当前用户 SQLite 工作区上的持久化虚拟查询。筛选与排序会编译为参数化 SQL，只解码最终命中的文章摘要，不会先把全库正文载入内存。可通过“全部/任一”逻辑组合文章状态、分类、标签、标题或正文、YAML/Properties 属性、更新或发布时间、字数和阅读量；每个集合还会保存最多三层排序、一个分组字段，以及列表、表格或卡片布局。选择集合不会移动或复制文章。

收藏与集合分开保存，并显示在侧栏。文章、Markdown 正文标题、全文搜索条件和全局文章图谱都可以从各自视图添加或取消收藏，之后直接跳转。

## 文章大纲与双链

文章阅读页右侧固定显示“文章面板”，无需滚动到正文底部即可使用大纲、反向链接、出链、未链接提及和一跳局部关系图。悬停在关联文章或图节点上会显示状态、摘要、标签和更新时间预览；点击即可打开文章。未链接提及会忽略已有 `[[双链]]`、行内与围栏代码以及 Markdown 链接；每条来源记录都可在并发冲突保护下，一键把所有安全提及转为双链。

双链会按标题、稳定 slug 或唯一的 `aliases` 属性进行不区分大小写的解析。点击尚不存在的目标会打开已预填标题的新文章草稿；`[[文章#标题]]` 与 `[[#标题]]` 会保留标题目的地并滚动到对应段落。导入的 aliases 同时进入全文搜索和文章链接图谱。

当阅读区域宽度不足时，右侧面板会自动收起；使用文章顶部的“文章面板”按钮可在独立面板中打开同一组导航工具。

## 阅读标签页与历史

阅读区顶部保留文章标签页，每个标签页都有独立的前进和后退历史。普通点击双链会在当前标签中继续导航；按住 `⌘` 点击正文双链、反向链接、出链、局部图节点或文章列表，会新建标签页。也可以从“最近文章”菜单明确选择在当前标签或新标签中打开。

固定标签页后，打开其他文章不会替换它，而是自动创建新的未固定标签。标签列表、固定状态、每个标签的历史和最近 20 篇文章会按用户记忆；使用 `⌘[` 和 `⌘]` 可以后退和前进。

“设置 → 阅读与编辑排版”可按用户调整正文宽度、系统/衬线/圆体、字号、行距、段距、阅读主题以及代码字体。阅读器、Markdown 预览和原生编辑器共享这些排版参数，不再依赖固定的 800 pt 正文宽度或 18 pt 编辑字号。

## 划词评论

阅读页右侧默认显示评论栏。拖选正文，或双击选择单词后，评论栏会自动引用所选原文并聚焦输入框；取消引用后也可以对整篇文章发表评论。评论支持回复和删除，删除主评论时会同时删除其回复。

划词评论会记录原文和最近的 Markdown 标题锚点。点击评论中的引用可回到对应章节；文章修改后会根据引用文字重新定位。评论保存在当前用户工作区的 SQLite 数据库中，并随本地备份一起保存。

## 写作模式

写作区顶部可在四种模式间切换；编辑模式会随当前任务布局保存：

- “专注写作”使用全宽行内预览编辑器，并隐藏文章设置与格式提示。
- “实时预览”在同一个可编辑正文中即时显示标题、强调、代码、引用、列表、链接和双链样式，同时弱化 Markdown 标记。
- “源码”只显示原始 Markdown，适合精确控制语法。
- “左右分栏”在左侧编辑源码、右侧显示包含图片和嵌入内容的完整渲染结果。

四种模式共享同一份正文、自动保存、撤销、图片粘贴和双链联想，不会因为切换布局丢失编辑状态。
也可以使用 `⌘⌥1` 至 `⌘⌥4` 依次切换这四种模式。

编辑页右栏可在“设置、属性、大纲、链接”之间切换。“属性”提供文本、列表、数字、日期、复选框和标签控件，在 SQLite/JSON 中保留类型并输出合法 YAML；还可以在不覆盖冲突值的前提下统一重命名整个工作区的属性。“大纲”随正文标题实时更新；“链接”同时显示正文双链、反向链接和未链接提及。右栏页签与显隐状态都可以保存在布局中。

## 任务布局与多窗口

“写作、阅读、审稿”保留为三套内置模板，同时可以把当前状态另存为任意命名工作区、重命名或删除自定义工作区。工作区快照会保存当前页面类型、文章标签与激活标签、编辑模式、左右面板页签与显隐、导航/编辑/阅读侧栏宽度，以及左右编辑分栏比例；编辑侧栏、阅读面板和编辑分栏支持直接拖动。布局按用户保存，菜单命令只作用于当前聚焦窗口。

## 页面性能与模块边界

主导航只挂载当前页面，不再预热并永久保留概览、文章、图谱、微博、编辑器和设置的完整 SwiftUI/NSHostingView 树。跨页面需要保留的内容放在轻量状态缓存中，例如微博时间线的折叠状态、单次浏览计数集合，以及图谱的筛选和缩放；离开页面后，图片解码视图、视频播放器、WebKit 和大列表都可以释放。

文章目录通过递归 FSEvents 接收文件级变更，700 毫秒内连续发生的事件会合并为一次增量同步。普通编辑只读取变更的 Markdown 并查询相关 SQLite 索引；目录导入只遍历对应子目录，事件丢失时自动退回完整校验。应用不再每两秒读取全库，并保留每 15 分钟一次的低频完整校验作为兜底。

每篇文章的双链引用和正文提及搜索文档会在正文写入事务中增量更新。打开文章关系面板时只读取摘要、当前文章的出链、可能指向它的入链和 FTS 候选提及；打开全局图谱时直接读取链接索引，不再重新解析全库 Markdown。旧工作区首次打开会一次性回填这些派生索引。

全局文章图谱支持标题、slug、标签和 aliases 搜索，按发布状态过滤、隐藏孤立节点、50–500 个节点上限，以及 50%–180% 缩放。绘制前会按节点连接度排序并裁剪，随后移除指向不可见节点的边，避免大资料库把全部节点同时交给 SwiftUI。

源码按功能 seam 拆为 Article、Editor、Article Properties、Backup、Import、Search、Graph Projection 与 Navigation Page State 模块。视图继续通过原有 `NativeAppModel` interface 操作，功能实现和测试则集中在对应模块，减少编辑器、导入、备份和搜索修改互相影响。

## 导入 Obsidian Vault

在“设置 → Obsidian Vault 导入”中选择 Vault。应用会先进行只读扫描，预览可导入文章、附件、slug 冲突和解析提示；只有再次确认后才会写入当前用户工作空间。

导入器支持常见 YAML Properties（包括列表属性与 aliases）、`[[文章]]`、`[[文章#标题|别名]]`、图片、视频及普通文件附件。Vault 内双链会映射为稳定的文章 slug，同时保留标题跳转目的地；附件会复制到文章自己的 `media/<slug>/` 目录。未识别的 YAML 属性会随文章保存在 SQLite 中，并继续写入 Markdown 导出。

这是单向导入，不是双向同步。应用不会修改、监听或回写 Obsidian Vault；复制到当前工作空间后的 Markdown 与附件成为权威数据，SQLite 保存可重建的文章索引。若当前工作区已有相同 slug（包括回收站文章），该笔记会在预览中标为冲突并默认跳过。

## 自动化与快捷指令

应用注册了 `leonbook` URL Scheme，可供 Raycast、浏览器书签、命令行启动器及其他本地自动化调用：

- `leonbook://new` 打开新文章草稿；可选的 `title`、`content`、`url` 参数可以预填网页剪藏，同时兼容 `name`、`text`、`source` 参数别名。
- `leonbook://open?slug=my-article` 按稳定 slug 打开已有文章。
- `leonbook://search?q=SQLite` 打开全局搜索并执行查询；不传查询时只打开搜索面板。
- `leonbook://today` 打开“动态 → 今天”，并清除其他动态筛选条件。

参数值需要进行百分号编码，尤其是空格、`#`、`&`、`/` 和完整来源网址。例如：`leonbook://new?title=网页%20剪藏&url=https%3A%2F%2Fexample.com`。

相同的四项操作也通过 App Intents 发布；构建后的应用至少启动一次后，会显示在 macOS“快捷指令”的 leon-book 操作中。Intent 在冷启动期间会排队，等当前工作空间及 SQLite 准备完成后再执行，不会因资料库尚未加载而丢失。

## 本地备份与恢复

在“设置 → 备份”中选择独立目录。数据变化会被合并处理，默认最多每小时生成一个自动快照。每个快照在逻辑上都包含完整资料库；未变化文件优先使用 APFS 写时复制克隆，无法克隆时复用上一快照或回退到复制。

默认策略保留 90 天、最多 60 个快照，并要求备份卷保留至少 10 GB 可用空间。设置页可调整全部策略、查看空间预估、在 Finder 中浏览快照、执行 SHA-256 校验，以及恢复整个资料库。恢复前会先创建安全快照，再用经过校验的暂存副本原子替换；备份目录不能位于当前数据目录内部，应用也不会自动上传备份。

## 构建与运行

系统要求：macOS 13 或更高版本，以及 Swift 5.10 或更高版本。请在项目根目录使用管理脚本：

```bash
./scripts/leonblog build
./scripts/leonblog open
```

构建后的应用位于 `macos/dist/leon-book.app`，使用临时签名，适合本机运行。

如需直接运行 SwiftPM 可执行文件：

```bash
swift run --package-path macos LeonBook
```

`LeonBook` 是当前 SwiftPM target 的内部名称；应用对外显示名称为 `leon-book`。

## 检查

```bash
./scripts/leonblog test
```

检查脚本会构建并运行原生单元测试和检查，不会打开应用窗口。

## 在文章中嵌入网页

文章 Markdown 支持把远程 HTTP(S) 网页直接嵌入正文。可以使用专用的 `embed` 代码块：

```embed
https://example.com
```

也可以直接粘贴独立的 iframe：

```html
<iframe src="https://example.com" title="Example" height="520"></iframe>
```

只接受 `http` 和 `https` 地址。内嵌网页可以直接交互，也可以点击“在浏览器中打开”使用外部浏览器。

## 在文章中插入 HTML 组件

使用专用的 `html-render` 代码块，可以在文章和写作实时预览中直接运行 HTML、CSS 和 JavaScript：

````markdown
```html-render height=360
<div style="padding: 20px; background: #2563eb; color: white">
  <h2>自定义组件</h2>
  <button onclick="this.textContent = '已点击'">点击</button>
</div>
```
````

`height` 可省略，默认值为 360，允许范围为 160–1200。普通的 `html` 代码块仍只展示源码，不会执行。HTML 组件使用独立的临时 WebKit 数据空间，点击其中的 HTTP(S) 链接会交给外部浏览器打开。请只运行自己信任的 HTML 和 JavaScript。

## 数据目录

应用按以下顺序选择数据目录：

1. `LEON_BOOK_WORKDIR`
2. `/Volumes/T7Shield/myblog/`

默认使用 `/Volumes/T7Shield/myblog/`；如果该目录不可用，首次进入应用时会要求选择工作目录并记住选择。如需使用其他目录，请设置 `LEON_BOOK_WORKDIR`。

默认用户为 `leon`。每位用户都有独立的 `workspaces/<user-id>` 目录。升级到多用户结构时，根目录中已有的文章、草稿、媒体、动态和活动记录会自动迁移到 `leon` 工作空间。首次启动时，已有 JSON 数据会自动导入工作空间的 SQLite 数据库。

如果安装了多个 macOS SDK，可以使用 `LEON_BOOK_SDK_PATH` 指定打包所用的 SDK：

```bash
LEON_BOOK_SDK_PATH=/path/to/MacOSX.sdk ./scripts/leonblog build
```
