# LeonApp Mac 功能集成

LeonBook 主导航的「聊天」内嵌 LeonApp Mac 0.15.3 当前工作区的完整聊天界面与实现，使用独立的 `LeonChat` SwiftPM 模块。原有写作、文章、微博、问答、待办、媒体、备份、自动化和手机同步功能继续保留。

| --- | --- |

| 发送、失败重试、待发恢复、增量同步、完整历史分页 | 原生聊天时间线与输入框 |
| 草稿、阅读位置和会话切换恢复 | 会话状态跨主导航页面保留；多个窗口共享连接与设备身份 |

| 清空当前会话及永久删除 | 沿用原确认界面与服务端权限 / 版本检查 |

## 首次使用和数据边界

首次进入「聊天」，填写与 LeonApp 相同的服务地址和访问令牌，即可同步该账号的服务器会话。已开启聊天通知时，LeonBook 启动即恢复连接并接收通知。首次配置仍从「聊天」进入。

集成客户端使用独立的 `com.leon-book.chat` 设置域、钥匙串服务和设备身份。不会改写独立 LeonApp 的令牌、待发队列或设备标识；不会自动搬迁它的本机未发草稿。服务器已确认的会话、消息、收藏与 Agent 由相同账号同步。

新归档优先调用应用随附的 `LeonBookCLI`，明确传入当前窗口的资料库根目录和用户，避免误用全局 CLI 默认目录。未完成归档继续使用原先固定的目标，保留已有防重与附件核验。资料库未连接时禁止退回其他默认目录。写入经过 LeonBook 原有自动化存储 / 刷新机制，不要求额外安装 CLI。

Mac 运行时通知沿用 LeonApp 轮询；退出应用后的推送仍依赖原有 APNs 配置，本次没有新增推送证书或部署服务端。所有聊天服务端功能沿用 LeonApp 现有接口；旧服务端继续显示原有升级提示。

## 构建与检查

```sh
./scripts/leonblog build
./scripts/leonblog test
# 仅聊天回归（构建后运行 13 个检查程序，无真实 AI 调用）
./macos/scripts/test-chat.sh
```

SwiftMath、公式字体、Markdown / KaTeX / Highlight.js / Mermaid 及第三方许可均随应用打包。构建输入追踪覆盖 `Vendor/`，资源缺失会使安装包需要重新构建。资源探针验证打包程序可以在构建缓存不可用时找到三组资源。

检查包括原 LeonApp 的消息协议、Markdown、公式、长表格、富文本、图片、输入、归档、归档恢复、会话切换、搜索与记忆场景，以及本次新增的资料库 / 用户隔离、未连接阻断和归档目标固定检查。界面渲染检查使用离屏窗口；不启动游戏，不自动打开或替换当前运行的应用。

## 1.1.1 回归修复

微博历史分页使用 `(created_at, id)` 作为游标，SQLite 可直接在活跃微博索引中定位。分页性能断言和同时间戳、筛选条件的分页回归均通过。

`LeonBookChecks` 的 21 项失败已解决。静态检查对齐现有的重启、富文本、兼容设置、收藏及微博媒体实现。微博附件、草稿编辑与筛选移入 `NativeAppModel+Moments.swift`，原有核心模型大小断言通过。

## 1.1.2 审查修复

归档弹窗由发起窗口持有。每次提交核对会话、Agent、资料库和待重试归档记录。首次归档使用本窗口资料库，恢复未完成归档时先展示固定的目标。保存失败会清理未引用的归档附件。

通知在启动阶段注册代理，账号切换会丢弃旧批次和游标。聊天窗口内 `⌘R` 同步聊天，`⌘,` 打开聊天设置。英文导航显示 `Chat`。构建会核验随包聊天渲染器和公式字体。

正式包可设置 `LEON_BOOK_CODESIGN_IDENTITY` 和 `LEON_BOOK_CODESIGN_TEAM_ID` 选择 Apple 签名身份。构建验证 App 和 CLI 的签发链及团队要求，配置后的工程会沿用签名身份。由 1.1.1 临时签名升级时，系统可能要求一次钥匙串授权。
