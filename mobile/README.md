# LeonBook 移动端

Android 和 iOS 共用同一套移动界面。文章、微博和待办保存在手机上，配对后可与 Mac 的一个工作区双向同步。Mac 上创建、修改或删除的内容在下次同步时反映到手机。本版手机可新建、编辑以及完成或重开待办。手机文章编辑器支持标题、加粗、项目列表、编号列表和正文插图。

## 构建应用

需要 Node.js 22.13 或更高版本。iOS 项目要求 Xcode 26 或更高版本，目标系统为 iOS 16 或更高版本。Android 项目需要 Android Studio 和 Android SDK 36。扫码组件要求 Android 8.0 或更高版本，设备需要版本 107 或更新的 Android System WebView。参见 [Capacitor 环境要求](https://capacitorjs.com/docs/getting-started/environment-setup)和[扫码组件说明](https://capacitorjs.com/docs/apis/barcode-scanner)。

```bash
cd mobile
npm ci
npm run sync
npm run ios       # 在 Xcode 中选择签名团队和手机，构建并安装
npm run android   # 在 Android Studio 中构建并安装 Debug 版本
```

仅构建网页资源可运行 `npm run build`。用浏览器本机调试可运行 `npm run dev`，配对地址可使用 `http://127.0.0.1:8765`。

## 在同一 Wi-Fi 上配对

1. 完成上面的 `npm ci`，再在项目根目录运行 `./scripts/leonblog build`。Mac 上运行同步服务也需要 Node.js 22.13 或更高版本。
2. 在 Mac 打开 LeonBook 的「设置 → 手机同步」，选择与手机位于同一局域网的地址，点「启动同步」。
3. 在 Mac 点「生成配对二维码」。手机打开 LeonBook 的「连接 Mac → 扫描配对码」，输入设备名称后扫码。也可复制并粘贴配对信息。二维码五分钟内有效，只能使用一次。如果系统请求相机或局域网权限，请允许。
4. 第一次配对会同步。之后打开手机 App、回到前台或网络恢复时会尝试同步。点首页的同步状态可查看待同步、失败和冲突条目，也可在此立即同步或重试。同步时仍可浏览本机已缓存的内容和附件，结束后从列表重新打开即可编辑或查看更新。

Mac 设置中的同步服务使用局域网 HTTP，手机无需安装证书。配对凭证和同步内容以明文传输，请在信任的 Wi-Fi 上使用。曾通过 HTTPS 配对的设备需要扫一次新二维码来更新地址。同一资料库的手机缓存和待同步修改会保留。

关闭 Mac 的设置窗口后，服务会继续运行。退出 Mac 应用会停止服务。以相同地址和端口重新启动时，已配对的设备会保留授权；如果局域网 IP 或端口变化，手机需要使用新的连接地址。Mac 设置里可查看已配对设备，并移除某个设备的同步权限。

开发时也可以用 `./scripts/leonblog mobile-sync --help` 启动终端服务。终端打印的直接连接凭证只在本次运行期间有效。已有可信 HTTPS 反向代理可代理至默认的本机地址 `127.0.0.1:8765`，并通过 `--url https://你的同步地址` 指定访问地址。

## 附件与离线查看

文章页沿用 Mac 侧栏的目录层级。在「全部目录」逐级打开子目录，点顶部目录路径可返回上一级。搜索会查找手机已保存的标题、正文、摘要、标签和目录路径，并显示正文命中片段。进入子目录后可切换搜索全部文章或当前目录及子目录。三个标签页各自记住搜索和浏览位置，重新打开 App 可继续浏览。旧版 Mac 同步服务可以从文章路径还原已有文章的目录，更新 Mac 同步服务后也会同步空目录。

从文章子目录点「新建」时，默认保存到当前目录，保存前可选其他目录，首次同步前也可修改。指定目录的文章离线保存在手机上，连接新版 Mac 同步服务后会写入选定目录。旧服务可继续同步保存在「未分类」的文章。

输入和插图会自动保存为本地草稿。重新打开编辑器会恢复草稿，也可从文章页「本地草稿」找到未完成的修改。点「保存文章」后，文章进入本机文章列表和同步队列。正文插图需要新版 Mac 同步服务，更新后图片会同步到原来的正文位置。

文章在全屏阅读页打开。有章节标题时，点「目录」可跳到对应章节。点「更多」可调节阅读字号或编辑文章，字号保存在手机上。正文图片滚动到附近时会自动加载，点图片可全屏查看。下滑关闭会回到正文原处，返回文章列表会保留目录、搜索和滚动位置。再次打开同一篇文章可在手机上续读。表格和代码块可单独横向滚动。

微博以瀑布流显示，图片滚动到附近时会自动加载。全屏看图时可左右切换、双击或双指缩放，放大后可拖动，恢复适屏后可下滑关闭。打开文章或微博的「附件」可下载并导出文件。已下载的附件断网后仍可查看。网络链接或未登记为附件的文件请在 Mac 查看，画板编辑在 Mac 进行。

单个附件最多 32 MiB，手机最多缓存 128 MiB，达到上限时优先移除最久未使用的文件。可在「配对设置 → 清除附件缓存」释放空间，正文和待同步修改会保留。切换工作区时会清除旧工作区的附件缓存。

编辑文章或微博时，点「添加附件」选择手机上的文件，保存后即可断网退出。下次点「同步」时，附件会随这条内容一起保存到 Mac，已经在 Mac 上的附件会保留。一条微博最多 9 个附件，支持常见图片、MP3 和 MP4，也可只发图片。文章可上传普通文件，一次最多新增 9 个附件。一次上传最多 64 MiB，手机最多保留 128 MiB 待上传文件。

## 处理冲突

手机发送更新时携带原来的版本。如果 Mac 已编辑或删除这一条，列表会标记「有冲突」，其余修改照常同步。点击该记录对照两边内容，可采用 Mac 版本、把手机内容及新选附件保存为新记录，或者在 Mac 记录还存在时手动合并。手动合并默认沿用 Mac 上手机未改过或已改回原值的字段，并检查所比较的 Mac 版本。新的文章副本保存为草稿，待办副本默认未完成。

如果请求发出后网络断线，下一次会使用同一操作编号和原内容重试。Mac 同步服务把处理结果写入用户应用数据目录下的 SQLite 日志。如果服务恰好在 Mac 写入后、结果记录前中断，手机会标记「待处理」。先在 Mac 核对保存结果，再处理手机保留的版本。

Mac 恢复备份后，原设备仍可连接。手机会保留恢复前的待同步修改并标记冲突，核对恢复后的 Mac 版本后再处理。请同时更新 Mac 和手机端以使用这项保护。

## 验证

```bash
npm --prefix mobile test
LEONBOOK_TEST_CLI="$PWD/macos/dist/leon-book.app/Contents/MacOS/LeonBookCLI" npm --prefix mobile test
```

测试使用临时资料库和回环端口，覆盖配对校验、Mac CLI 双向读写、同步重试、并发修改、删除、冲突副本和附件访问。可执行文件路径由可选变量 `LEONBOOK_TEST_CLI` 提供。
